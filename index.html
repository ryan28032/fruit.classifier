02 UNDER THE SKIN

Teaching a computer
to spot the good stuff.

Fruit classification is an image recognition task. A model learns visual patterns from labeled examples, then uses those patterns to make a prediction on a new photo.

01 — COLLECT
🍎🍊🍐

Gather examples

Build a balanced dataset of fruit images, each tagged with the right label.

02 — TRAIN

Teach the model

Train a computer vision model to recognize shapes, colors, and textures.

03 — PREDICT
🍋→?

Make a prediction

Send a new image to the model and return its best-guess fruit class.

03 A NOTE ON THE PROJECT

Built to learn.
Ready to grow.

FruitLens runs MobileNet with TensorFlow.js. It is a general-purpose ImageNet model—not a custom fruit-only model—so predictions can vary. Inference happens in your browser; the first use downloads the model files.
